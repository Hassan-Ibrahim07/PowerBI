# Power BI Advanced Visualizations: Combo Charts Analysis

## 📊 Project Overview
This repository contains a Power BI project (`3_2_combo_charts.pbix`) dedicated to advanced data visualization techniques, specifically focusing on **Combo Charts** (Line and Column charts). Combo charts are essential for comparing multiple metrics with differing value scales—such as volume and percentage rates—within a single, cohesive visual.

## 🎯 Objective
To demonstrate proficiency in translating complex datasets into clear, actionable business insights using Power BI. This project highlights the ability to identify trends, compare contrasting metrics, and build interactive dashboards that support data-driven decision-making.

## 🛠️ Technical Skills Showcased
- **Primary Tool:** Power BI Desktop
- **Data Visualization:** Dual-axis plotting (Line and Clustered/Stacked Column Charts)
- **Data Modeling:** Structuring relationships for accurate cross-filtering
- **DAX (Data Analysis Expressions):** Creating calculated columns and measures for custom metrics
- **Analytical Foundation:** Statistical analysis, trend identification, and data storytelling

## 📈 File Highlights (`3_2_combo_charts.pbix`)
The included Power BI file explores the following core concepts:
1. **Metric Comparison:** Overlaying continuous trend lines (e.g., profit margins, month-over-month growth) against categorical volumes (e.g., total revenue, unit counts).
2. **Dashboard Optimization:** Combining two visuals into one to save screen real estate while enhancing analytical depth.
3. **Correlation Tracking:** Quickly spotting anomalies or correlations between absolute numbers and relative percentages.
